# مُطابِق — نسخة بدون خادم تديره أنت (Netlify)

هذي نسخة من الموقع مبنية عشان تشتغل كاملة (تحليل + قائمة انتظار) بدون ما تحتاج تشغّل أي شيء بنفسك — لا Node.js، لا XAMPP، ولا أي "خادم" تراقبه. Netlify تسوي الشغل الخلفي تلقائياً.

## وش الفرق عن النسخة اللي فيها Backend منفصل؟

| | النسخة القديمة (mutabiq-backend) | هذي النسخة (Netlify) |
|---|---|---|
| تشغيل يدوي مطلوب منك | نعم (npm start دايماً) | لا — بعد أول رفع، كل شي تلقائي |
| قاعدة بيانات | SQLite تديرها بنفسك | Netlify Forms تحفظ التسجيلات وتقدر تصدّرها CSV من لوحة Netlify |
| تحليل السيرة الذاتية | عبر Express + مفتاحك | عبر Netlify Function (نفس الفكرة، بس ما فيه خادم تشغّله) |
| تسجيل دخول (بريد/لينكدإن) | موجود في mutabiq-backend | غير موجود في هذي النسخة المبسّطة |

إذا تحتاج تسجيل دخول حقيقي بحسابات مستخدمين لاحقاً، ذاك يبقى يحتاج نسخة الـ Backend الكاملة. هذي النسخة تركّز على تشغيل الموقع + التحليل + قائمة الانتظار فقط، بأقل جهد صيانة ممكن.

## خطوات الرفع (مرة وحدة بس)

1. أنشئ حساب مجاني على https://github.com إذا ما عندك.
2. أنشئ مستودع (repository) جديد وارفع فيه **كل محتوى هذا المجلد** كما هو (بما فيها مجلد `netlify` وملف `netlify.toml`).
3. أنشئ حساب مجاني على https://netlify.com (تقدر تسجّل بحساب GitHub مباشرة).
4. من لوحة Netlify: **Add new site → Import an existing project** واختر المستودع اللي رفعته.
5. اترك إعدادات البناء كما هي (Netlify يقرأها تلقائياً من `netlify.toml`) واضغط **Deploy**.
6. بعد الرفع، روح لـ **Site settings → Environment variables** وأضف متغير باسم `ANTHROPIC_API_KEY` وقيمته مفتاحك من Anthropic. هذا الخطوة الوحيدة اللي فيها "سر" تكتبه، ويبقى محفوظ عند Netlify فقط، ما يظهر لأي زائر.
7. أعد النشر مرة (Deploys → Trigger deploy) عشان يقرأ المتغير الجديد.

خلاص — موقعك صار على رابط عام (مثل `https://xyz.netlify.app`)، يشتغل فيه التحليل وقائمة الانتظار، وما فيه شيء تشغّله أو تراقبه بعدين.

## وين تشوف تسجيلات قائمة الانتظار؟

من لوحة Netlify: **Site → Forms** — بتلاقي كل بريد تسجّل، مع خيار تصدير الكل كملف CSV.

## ملاحظة عن اللهجة/التسمية

لو حبيت لاحقاً تربط دومين خاص فيك (مثل mutabiq.com) بدل رابط netlify.app، هذا يصير من **Site settings → Domain management** بنفس اللوحة، بدون أي تعديل على الكود.
